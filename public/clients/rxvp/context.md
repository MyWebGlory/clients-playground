# RXVP Client Context

## Who RXVP Is
RXVP is positioned as the first and only global speakers bureau for the life sciences. The client work here is centered on leadership programming, speaker visibility, and event participation across global life sciences audiences.

Website: https://www.rxvp.org/

## Known Contact
- Bonnie Lappin, contact listed on current project materials: bonnie@rxvp.org

## Current Project Track
The existing RXVP source repo was a fast one-off design workspace. It included a polished static HTML partnership-package page, an International Women's Day recap section, shared RXVP images, and uploaded source/reference assets.

The first normalized projects in this playground are:
- `partnership-package`: A4 one-page RXVP 2026 Partnership Package.
- `international-womens-day`: Long-form International Women's Day event recap section.

## Brand And Design Notes
- Visual style uses premium life-sciences leadership cues: deep purple, gold, refined typography, and executive-event framing.
- Keep outputs polished, concise, and sponsor/partner ready.
- Existing work uses a more editorial/flyer-like static HTML style; future work should normalize structure without flattening the brand personality.
- Prefer clear hierarchy, limited copy, and confident calls to action.

## Known Program Details
- RXVP 2026 programming includes eight virtual panel events in September, October, and November 2026.
- Panels are described as hosted across Asia, India, Europe, Africa, and the Americas.
- Partnership package includes speaker participation, event access, a customized panel event, watch-party facilitation support, speaker development support, visibility/promotion, and preferred pricing.
- Current annual partnership fee shown in source material: $2,500.
- International Women's Day recap references March 4-6, 2026 and a global collection of senior leaders across five continents.

## Operational Assumptions
When asked to create RXVP assets:
1. Check this client context before writing copy or changing design direction.
2. Reuse RXVP assets from `public/clients/rxvp/assets/`.
3. Keep source/reference uploads in `public/clients/rxvp/assets/source/` unless explicitly asked to turn one into a project.
4. Put every web deliverable under `public/clients/rxvp/projects/<project-slug>/index.html`.
5. Keep asset paths relative from the project file, usually `../../assets/images/...`.
